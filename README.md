# NearFeast brand media

Public images and videos for NearFeast's own social media posts. Metricool fetches them by their raw
link, for example:

https://raw.githubusercontent.com/hoseinzadeh/nearfeast-brand-media/main/explainers/found-by-dish-9x16.mp4

- `explainers/` – the animated product explainers as video: `<name>-9x16.mp4` (Reels, Shorts, TikTok,
  Stories), `<name>-16x9.mp4` (YouTube, LinkedIn, Facebook), plus `-cover.jpg` stills.
- `posts/YYYY-MM-DD/` – media the social agents make for a specific post.

Everything here is public. Never put customer data, private photos or anything unreleased here.
